## 🛡️ Complete Cybersecurity Learning Curriculum (8 Core Domains)

<div class="grid cards" markdown>

-   :material-shield-network:{ .lg .middle } **01. Network Security**
    
    ---
    
    Master the 7-layer OSI model, TCP/IP handshakes, Stateful vs. NGFW firewalls, IDS/IPS packet analysis (Wireshark/Suricata/Zeek), and Zero Trust Network Access (ZTNA).
    
    [:octicons-arrow-right-24: Start Network Security Module](domains/network-security.md)

-   :material-cloud-lock:{ .lg .middle } **02. Cloud Security**
    
    ---
    
    Secure AWS, Azure, and GCP workloads. Learn the Shared Responsibility Model, SSRF-to-IMDSv2 defense, Kubernetes container hardening, and Terraform IaC scanning.
    
    [:octicons-arrow-right-24: Start Cloud Security Module](domains/cloud-security.md)

-   :material-laptop-off:{ .lg .middle } **03. Endpoint Security**
    
    ---
    
    Understand how ransomware, fileless malware, and LOLBins operate. Master EDR kernel telemetry, Windows Event IDs, Sysmon hunting, and CIS OS hardening.
    
    [:octicons-arrow-right-24: Start Endpoint Security Module](domains/endpoint-security.md)

-   :material-code-braces:{ .lg .middle } **04. Application Security (AppSec)**
    
    ---
    
    Deep-dive into the OWASP Top 10, side-by-side Vulnerable vs. Secure code examples (SQLi, Command Injection, SSRF), and automated CI/CD DevSecOps pipelines.
    
    [:octicons-arrow-right-24: Start AppSec Module](domains/application-security.md)

-   :material-account-key:{ .lg .middle } **05. Identity & Access Management (IAM)**
    
    ---
    
    Compare DAC, MAC, RBAC, and ABAC access control models. Master Kerberos tickets, SAML 2.0, OAuth 2.0/OIDC, and phishing-resistant FIDO2/WebAuthn passkeys.
    
    [:octicons-arrow-right-24: Start IAM Module](domains/iam.md)

-   :material-database-lock:{ .lg .middle } **06. Cryptography & Data Security**
    
    ---
    
    Learn Symmetric (AES-GCM) vs. Asymmetric (RSA/ECC) encryption, SHA-256/Argon2id hashing, Public Key Infrastructure (PKI), TLS 1.3 handshakes, and immutable backups.
    
    [:octicons-arrow-right-24: Start Data & Crypto Module](domains/data-security.md)

-   :material-factory:{ .lg .middle } **07. OT & Critical Infrastructure**
    
    ---
    
    Protect power grids, water plants, and SCADA/PLC networks. Understand IT vs. OT priority inversion, the Purdue Model (Levels 0–5), and Modbus/DNP3 passive forensics.
    
    [:octicons-arrow-right-24: Start OT/ICS Module](domains/ot-infrastructure.md)

-   :material-brain:{ .lg .middle } **08. AI & LLM Security**
    
    ---
    
    Defend Large Language Models, RAG vector pipelines, and autonomous agents against Direct/Indirect Prompt Injection, model poisoning, and supply-chain attacks.
    
    [:octicons-arrow-right-24: Start AI Security Module](domains/ai-security.md)

## 🏛️ Strategic Framework: NIST Cybersecurity Framework (CSF) 2.0

Every tutorial and daily incident report on this platform maps directly to the six core functions of **NIST CSF 2.0**:

| Function | Strategic Mandate | Tactical Implementation |
| :--- | :--- | :--- |
| **Govern (GV)** | Organizational context, risk strategy, supply chain oversight, and roles. | Security policies, third-party vendor risk audits, and board accountability. |
| **Identify (ID)** | Asset management, software dependency inventory, and risk assessment. | Automated attack surface discovery, SBOM generation, and vulnerability scanning. |
| **Protect (PR)** | Identity management, network isolation, data encryption, and platform hardening. | FIDO2 MFA, network micro-segmentation, AES-256 encryption, and immutable backups. |
| **Detect (DE)** | Continuous security monitoring, anomaly analysis, and threat hunting. | SIEM/XDR correlation rules, Zeek protocol logs, and Suricata IDS alerts. |
| **Respond (RS)** | Incident management, forensic triage, containment, and eradication. | Automated EDR host isolation, token revocation, and memory/disk forensics. |
| **Recover (RC)** | Incident recovery plan execution and verified restoration of operations. | Rebuilding from air-gapped WORM snapshots and post-incident architecture hardening. |
