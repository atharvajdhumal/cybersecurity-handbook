## 🏛️ Strategic Framework: NIST CSF 2.0

All defensive tooling and daily incident triage on this hub are mapped across the six core functions of NIST CSF 2.0:

| Function | Strategic Mandate | Tactical Implementation |
| :--- | :--- | :--- |
| **Govern (GV)** | Organizational context, policy, risk tolerance, and third-party oversight. | Setting organizational profiles, supply chain audits, and board reporting. |
| **Identify (ID)** | Comprehensive asset, identity, software dependency, and vulnerability discovery. | Passive topology mapping, automated SBOMs, and attack-surface analysis. |
| **Protect (PR)** | Preventative safeguards across networks, cloud workloads, endpoints, and credentials. | FIDO2 MFA, micro-segmentation, immutable backups, and least-privilege RBAC. |
| **Detect (DE)** | Anomaly detection, behavioral hunting, and indicator correlation. | SIEM/XDR correlation rules, Zeek metadata extraction, and Suricata alerting. |
| **Respond (RS)** | Rapid forensic containment, asset isolation, and incident communication. | Host network quarantine, OAuth token revocation, and forensic PCAP triage. |
| **Recover (RC)** | Validated restoration of operational systems and integrity verification. | Restoring from out-of-band immutable snapshots and post-incident lessons learned. |
