# Enterprise Cybersecurity Architecture & Threat Intelligence Hub

Welcome to the open-access reference architecture for modern cyber defense, continuous threat modeling, and real-time intelligence[cite: 6]. This platform unifies technical controls across eight primary cybersecurity disciplines under the **NIST Cybersecurity Framework (CSF) 2.0**[cite: 6].

---

## Strategic Governance: NIST CSF 2.0

Modern defensive security aligns across six core functions established by NIST CSF 2.0[cite: 8]:

| Function | Focus Area | Core Operational Objective |
| :--- | :--- | :--- |
| **Govern (GV)** | Strategy & Oversight | Establishing organizational risk tolerance, supply chain policies, and board accountability. |
| **Identify (ID)** | Asset & Risk Profiling | Continuous inventory of hardware, software, identities, data flows, and external exposures[cite: 7]. |
| **Protect (PR)** | Preventative Defenses | Enforcing identity least-privilege, network isolation, cryptographic key management, and fleet hardening[cite: 7]. |
| **Detect (DE)** | Continuous Monitoring | Correlating telemetry from endpoints, network sensors, and cloud logs to identify anomalies. |
| **Respond (RS)** | Incident Containment | Executing rapid isolation of compromised identities, host quarantine, and communication protocols. |
| **Recover (RC)** | Resilience & Restoration | Rebuilding assets from verified immutable backups and validating root-trust cryptographic integrity[cite: 8]. |
